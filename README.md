## Which CV to use

Use **`andler-cv.pdf`** by default — it is the standard version and should be the one
attached anywhere no preference is stated.

Use **`andler-cv-ni.pdf`** only when the application is Nicaragua-facing, or when
nationality is explicitly requested on the form. It is the same CV with one added line
directly under the residence line:

```
Nacionalidad: Nicaragüense · Nicaraguan
```

Nothing else differs between the two files.
